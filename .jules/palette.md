## 2024-05-24 - Pure Icon Button Accessibility
**Learning:** For accessibility on icon-only interactive elements (like the Eye/Lock/Trash buttons in API Keys Settings), `title` attributes act as a tooltip for visual users but don't consistently provide the exact programmatic accessible name and state to screen readers. Adding explicit `aria-label` and `aria-pressed` (for toggles) is required to comply with WCAG standards for icon-only buttons.
**Action:** When creating or reviewing pure icon buttons, especially those that toggle state (e.g., visibility, encryption), always ensure they have an explicit `aria-label` describing the action, and if they act as a toggle, an `aria-pressed` attribute reflecting the current boolean state.
